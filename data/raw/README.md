# Raw data provenance

- supplied_baseline_configuration.csv: transcription of baseline parameter and outcome values stated in the user's manuscript PDF.
- table_iv_values_as_supplied.csv: survival probabilities transcribed from the separately provided completed Table IV output PDF. These are reference values from that document, not outputs generated by the current script's seed schedule.
- supplied_table_V_VI_candidate_values.csv: values parsed from the separately supplied candidate Tables V/VI PDF. These are retained with explicit provenance notes; in particular, the A2 latency values were parsed from a malformed extraction and should be verified against the original CSV. The source run logs and implementation were not provided.
