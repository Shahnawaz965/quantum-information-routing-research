# Manuscript

The paper reviewed for this repository is titled **“Simulating Information Routing in Quantum Networks.”**

The original manuscript PDF supplied in the conversation is not currently committed in this repository. Add the final author-approved PDF to this directory manually if the repository is intended to archive the manuscript as well as its code.

The paper reports a SeQUeNCe baseline, but the available companion baseline code is a SimPy reconstruction and is not a SeQUeNCe implementation. A reproducible SeQUeNCe replication still requires the original SeQUeNCe model, topology/configuration files, seed list, and event logs.
